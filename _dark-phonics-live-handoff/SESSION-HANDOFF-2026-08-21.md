## Gotchas (all still true, plus new ones)

- **`git rm` through a subagent silently failed today** — the agent reported success and
  the files were still on disk. Always verify a deletion with `ls`/`git status`, never
  trust the report.
- **Isolated-world blind spot is real.** `Control_Chrome__execute_javascript` cannot see
  page globals; `ASSETS` reads as undefined. Inject a `<script>` into the main world and
  pass results back via `document.title`.
- FUSE mounts cannot unlink — git deletes/renames must go through a native shell.
- Railway builder-queue stalls: check status.railway.com; an empty commit re-triggers.
- CSP `next.config.ts` ~line 254 must allowlist media hosts.
- `cap add android` wipes CAMERA permissions from the manifest.
- robots.txt blocks WebFetch on `/api/*` and `/montree/dashboard/*`; Cloudflare can serve
  stale pages — use Chrome for anything time-sensitive.
- ElevenLabs speech-to-speech wants the form field **`audio`**, not `file` (422 otherwise).
