# The bucket — STL files for the shelf miniatures

This folder is the drop point for the 3D-printable miniatures used by both
shelves. The table that documents them — quantities, sizes in mm, print notes
and the total (34 pieces across 16 objects) — lives on the Writing Shelf page,
`public/dark-phonics-shelves.html`, in the **3D Print** section
(`/dark-phonics-shelves.html#print3d`). The Talking Shelf page points here too:
set two of its eight miniatures is printed from these files rather than bought,
because Behind the Screen only works if the two sets are identical. Print at one
scale, one colour per object, matte PLA, nothing under 35 mm in any direction —
the youngest children are two.

The page links each row to `/dark-phonics-shelf/3d/<file>` and HEAD-probes every
URL on load: a file that is present becomes a live download link, a file that is
missing keeps a muted "not yet" chip. So: **drop the .stl in, push, the link
appears — nothing else to edit.** Use exactly these filenames:

- Actors — `cat.stl`, `pig.stl`, `dog.stl`, `nut.stl`
- Places — `bed.stl`, `pot.stl`, `tin.stl`, `hat.stl`
- Writing Shelf only — `sun.stl`, `mug.stl`, `pan.stl`, `mop.stl`, `peg.stl`,
  `bin.stl`, `cot.stl`, `kit.stl`
- Optional — `grammar-tokens.stl`, `counter.stl`
