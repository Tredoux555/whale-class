# Midjourney prompts — Week 4 · My Feeling (Sep 21–24, a four-day week)

37 images: **8 posters** (`--ar 3:4`, save 928×1232) · **28 cards** (`--ar 1:1`, save 1000×1000) · **1 badge**.

**How to use:** run each prompt as written, upscale the best one, save it as the PNG filename at the
start of the line into `~/Downloads/circle-time-mj/`, then convert to JPEG into
`public/circle-time-images/week4/` (see `docs/circle-time/mj-prompts-README.md` §9). The filenames
below match the `src` attributes in `circle-time-week4.html` exactly — do not rename them.

**Locked style suffix** (already appended to every prompt below, verbatim):
`, soft gouache storybook illustration, warm muted palette, simple rounded shapes, thick soft outlines, plain off-white background, children's picture-book art. no text, no words, no letters, no numbers, no captions, no speech bubbles, no border, no watermark, no frame`

Cards are deliberately hyper-literal and singular — one object or one face, centred, nothing else in frame.

**Moderation note:** this week is full of faces. Keep children generic and clothed — "one small child",
never an age, a body description or anything about skin — and if a face prompt is flagged, add
`flat cartoon illustration, children's book art, no photo-realism` and resubmit (see README §7).
